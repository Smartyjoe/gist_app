# Gistly

**Gistly** is a modern social platform built around real conversations, expressive storytelling, and voice-first interaction.
The goal of Gistly is to move beyond passive scrolling by giving users powerful ways to **share ideas, react instantly, and participate in live conversations**.

Unlike traditional social media platforms that prioritize static content, Gistly is designed to make **communication feel alive** — through voice replies, hot takes, dynamic stories, and live interaction.

This repository contains the **frontend application currently under active development**, focused on building a clean, scalable UI architecture that will later integrate seamlessly with backend services.

---

# Vision

Most social platforms focus on **content consumption**.

Gistly focuses on **conversation**.

Users should be able to:

* Share quick thoughts
* React instantly
* Join discussions
* Speak instead of type
* Participate in live conversations

The platform combines elements of modern social media with a strong emphasis on **voice, interaction, and discovery**.

---

# Core Features

## Social Feed

The main feed displays posts from people a user follows along with relevant recommendations.

Users can interact with posts through:

* Likes
* Comments
* Shares
* Voice Replies
* Hot Takes

The feed is designed to remain **clean and readable while still encouraging discussion**.

---

## Voice Replies

Users can respond to posts using short **voice replies**.

Instead of typing comments, users can record quick responses which appear in the comment thread as waveform players.

This creates a more natural conversation experience and aligns with the platform’s focus on authentic expression.

---

## Hot Takes

The **Hot Takes** feature introduces a dedicated space for opinions on posts.

Users can attach their perspective or reaction to a post without cluttering the traditional comment thread.

Hot Takes are displayed as a separate expandable section beneath posts and can be sorted by engagement.

This encourages healthy debate and deeper conversations around content.

---

## Stories

Gistly includes a rich story system designed for quick, engaging updates.

Users can create multiple types of stories:

* Camera Story
* Gallery Story
* Text Story
* Voice Story

Stories appear in a horizontal strip at the top of the feed and expire after 24 hours.

### Story Features

Stories support:

* Text overlays
* Animated typography
* Background styles
* Polls
* Emoji reactions

Text stories use large, expressive typography with animated backgrounds to make them visually engaging.

---

## Voice Stories

Voice stories allow users to share short audio messages accompanied by animated waveform visuals.

These stories auto-play when viewed and provide a more personal way to share updates.

---

## Story Polls

Users can add quick polls to stories to gather opinions from their audience.

Poll results update dynamically as viewers vote.

---

## Story Reactions

Viewers can quickly react to stories using emoji reactions such as:

❤️ 😂 😮 🔥 👏

Reactions appear as subtle floating animations to maintain a lively viewing experience.

---

## Live Streaming

Gistly includes a fully immersive live streaming system.

Users can broadcast live video to their followers and interact in real time.

### Live Features

Live streams support:

* Real-time comments
* Viewer counts
* Floating reactions
* Co-host streaming

The co-host feature allows the streamer to invite another user to join the broadcast, creating split-screen conversations.

---

## Live Discovery

Live broadcasts are surfaced contextually within the feed when relevant.

Instead of permanently occupying screen space, live streams appear dynamically when:

* Friends are broadcasting
* Trending live sessions are available
* Recommended streams match user interests

This keeps the feed clean while still enabling discovery.

---

## Live Replay Highlights

After a livestream ends, users can select a **30–60 second highlight** from their stream and publish it as a story.

This allows creators to share the most engaging moment from their broadcast with followers.

---

## Voice Status

Users can record a short **voice status** that appears on their profile.

This acts as a quick audio introduction or update and can be replaced anytime.

---

# UI Architecture

The application is being developed with a **modular component architecture** to ensure scalability as new features are introduced.

Major UI modules include:

* Post Interaction Components
* Story Components
* Live Streaming Components
* Voice Interaction Components
* Profile Components

Each module is designed to remain independent while maintaining visual and functional consistency across the app.

# Design Principles

The Gistly interface follows several guiding principles:

### Simplicity

Every screen should feel intuitive and uncluttered.

### Expressiveness

Users should be able to express themselves through voice, text, reactions, and live interactions.

### Speed

The interface must remain responsive and smooth even as features expand.

### Scalability

The architecture must support future features without requiring major structural changes.
